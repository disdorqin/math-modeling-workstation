# 2010 C题 输油管布置问题(优化模型)提炼稿

## 1. 结构大纲
1. 问题重述(输油管线布置,目标=总费用最省)
2. 问题分析:管线敷设费用=管线长度×单位造价(跨越不同区域造价不同)
3. 问题一:在只考虑管线本身造价时,建立总费用最小化优化模型
4. 问题二:计入附加费用(如拆迁/跨越河流等)后的扩展模型
5. 问题三:更一般情形(多点/多目标)推广
6. 模型评价与改进

## 2. 摘要写法
- 开篇一句交代问题本质:"以总费用最省为目标函数,建立了多个优化模型"
- 每个问题一段,先写"对问题X:……建立……模型"
- 结尾给出求解结论与费用结果

## 3. 建模套路
- 先抽象几何约束(管线长度如何随布置方式变化),再叠加费用函数
- 从最简情形出发,逐步放松假设逐问深化(问题一→二→三)
- 优化类 C 题标准范式:目标函数 + 决策变量 + 约束条件

## 4. 图表风格
- 管线布置示意草图辅助说明几何关系
- 分情形费用结果对比表
- 图表与模型公式配合,不单独堆图

## 5. 语言特点
- 平实陈述,方案并列使用"从不同角度出发"
- 每个模型的建立缘由一句话交代,不空谈背景

## 6. 评分亮点
- 由简到繁的模型递进结构清晰,评分者易跟随
- 目标函数直接锚定题面"总费用最省",不跑题
