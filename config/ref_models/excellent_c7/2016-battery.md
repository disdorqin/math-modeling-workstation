# 2016 C题 电池剩余放电时间预测 提炼稿

## 1. 结构大纲
1. 问题背景(铅酸电池恒流放电,电压单调下降至保护电压9V)
2. 问题1:对20A~100A共9条放电曲线做二次多项式拟合
   - 建立放电时间-电压关系式
   - 建立剩余放电时间-电压关系式
   - 提取231个样本点计算平均相对误差(MRE,约0.0035~0.0178)
   - 预测电压9.8V下各电流强度的剩余放电时间,与实测值对比误差<0.0007
3. 问题2:拟合9条曲线系数随电流的变化
   - 发现二次项/一次项/常数项系数与 log(I) 线性相关(拟合度>95%)
   - 得到任意电流强度下的放电曲线 → 预测模型
4. 结论

## 2. 摘要写法
- 每问题一段,公式化地交代"建立XX模型→按题定义计算误差→预测并与实测对比"
- 数字密度高:R²>99%、MRE 0.0035~0.0178、预测误差<0.0007,全量化
- 先给方法再给数字,摘要即可评估模型质量

## 3. 建模套路
- 曲线拟合类 C 题:对离散数据先选函数形式(多项式)→ 拟合 → 误差按题定义计算 → 外推预测
- 泛化技巧:把各条曲线的拟合系数再拟合成电流的函数(系数随 log(I) 线性),实现任意电流预测
- 检验闭环:预测值必须回落到实测数据验证(找电压最接近的实测值算相对误差)

## 4. 图表风格
- 多条放电曲线同图对比,图注标注电流强度
- R²/误差数据用表集中呈现
- 实测点与拟合曲线叠加,直观展示贴合程度

## 5. 语言特点
- 句式简练,信息密度高
- 用"拟合度""平均相对误差"等量化语言贯穿
- 每步解释"为什么这样做"(为找系数随电流规律而取对数)

## 6. 评分亮点
- 全流程量化(每步都有误差数字),评分者无需自行验证即可信服
- 问题2的"系数再拟合"是亮点,把9条孤立曲线推广成任意电流的解析解
- 严格按题目定义的 MRE 计算误差,与题面对齐
