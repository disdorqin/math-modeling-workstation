# 2020 C题 银行信贷决策分析 提炼稿

## 1. 结构大纲
1. 问题背景(银行对中小微企业信贷风险评估与放贷决策)
2. 问题1:有信贷记录企业
   - 特征提取(企业实力/发展潜力/供求关系/抗风险能力,20个特征)
   - SoftVoting 集成学习算违约风险(准确率97.6%,AUC 99.42%)
   - 多目标规划:利润最高+风险最小 → 放贷额度/利率/期限
3. 问题2:无信贷记录企业
   - 用问题1模型预测违约风险
   - XGBoost 训练信誉评级多分类(准确率87.8%)
   - 再套多目标规划得策略
4. 问题3:灵敏度/策略分析
5. 结论

## 2. 摘要写法
- 开门见山交代决策链:"评估信贷风险→确定是否放贷及额度/利率/期限"
- 每个模型给出性能硬数字(97.6%、99.42%、87.8%)
- 关键词:集成学习、多目标规划、违约风险、信誉评级

## 3. 建模套路
- 决策类 C 题标准三阶段:风险评估 → 评级/分类 → 优化决策
- 集成学习做风险打分(多基分类器投票),比单一模型稳健
- 决策问题用多目标规划落地,给出可执行方案而非只给概率

## 4. 图表风格
- ROC 曲线/AUC(模型性能)
- 特征重要性排序图
- 信贷策略(额度/利率/期限)方案表

## 5. 语言特点
- 业务与算法术语并用(SoftVoting/XGBoost 与贷款额度/利率)
- 决策链表述清晰,每问结论落到"策略"

## 6. 评分亮点
- 集成学习+多目标规划组合,方法现代且贴合题意
- 模型性能指标全量化(AUC 99.42% 极具说服力)
- 输出可直接执行的信贷策略,实用性强
