# 2018 C题 大型百货商场会员画像描述 提炼稿

## 1. 结构大纲
1. 问题背景(电商冲击,会员流失,精细化管理需求)
2. 问题1:会员与非会员对比分析
   - SQLServer 导入数据 → 按单据号提取特征
   - 对比会员/非会员的消费金额、购买数量、平均价格
   - 列表对比差异与会员价值(表4-4)
3. 问题2:会员购买力聚类
   - 以消费金额、消费次数为特征,K-means 聚类
   - K值用 D=类内平均距离/类间平均距离 确定,K=4
   - 四类会员:大众(45678人)/黄金(2708人)/铂金(348人)/砖石(17人)
4. 问题3:会员生命周期阶段划分
   - 以最近未消费天数、消费次数为指标
   - 五阶段:引入-成长-成熟-休眠-流失
5. 结论与营销建议

## 2. 摘要写法
- 用背景铺垫引入价值("完善会员画像…节约营销成本")
- 每问一段:数据处理方式 → 方法(K-means) → 结果(类别与人数)
- 聚类结果用标签化数字呈现,摘要即有结论

## 3. 建模套路
- 数据挖掘类 C 题:数据预处理 → 特征提取 → 无监督聚类 → 结果解读
- 聚类 K 值给确定依据(公式),不用拍脑袋
- 把统计结果翻译成业务语言(会员等级/生命周期),提升应用价值

## 4. 图表风格
- 聚类中心点表(各类别特征值)
- 分群人数分布
- 会员/非会员差异对比表

## 5. 语言特点
- 业务化表达(大众/黄金/铂金/砖石会员),可读性强
- 每个问题的数据来源与处理工具交代清楚(SQLServer/SPSS)

## 6. 评分亮点
- K值选取有量化依据,方法严谨
- 结果业务化解读,画像直接可用
- 特征选择(消费金额+消费次数)贴合购买力本质
