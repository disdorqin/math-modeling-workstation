# 2022 C题 古代玻璃制品成分分析与鉴别 提炼稿

## 1. 结构大纲
1. 问题背景(风化玻璃文物成分分析)
2. 问题1:风化与成分统计规律
   - 数据预处理(剔除无效数据,成分数据定和1)
   - 中心化对数比变换(CLR)消除定和限制
   - 卡方检验(>20%期望计数<5用Yates校正)分析风化与颜色/类型/纹饰关系
   - 描述统计量(均值/最大最小/标准差/变异系数/偏度/峰度)+箱线图
   - 回归方程预测风化前化学成分含量(预测结果保证累计和100%)
3. 问题2:玻璃类型鉴别
   - 决策树监督学习分类铅玻璃/高钾玻璃(精确率/召回率/准确率/F1 全为1)
   - 按类型分析化学成分差异
4. 结论

## 2. 摘要写法
- 以数据特性切入:"将化学成分转化为成分数据(定和1)→中心化对数比变换"
- 每个子问给出方法与关键数字(F1全为1,累计和100%保证)
- 方法选择理由(卡方前提不满足时Yates校正)体现严谨

## 3. 建模套路
- 成分数据类 C 题:定和约束 → CLR 变换 → 统计检验/回归/分类
- 统计检验注意前提条件并给出校正方案,是专业度体现
- 用监督学习做鉴别,用回归做反演,两类任务分工明确

## 4. 图表风格
- 箱线图呈现多组分布(反映散布范围与中心位置)
- 描述统计量汇总表
- 分类模型性能指标表

## 5. 语言特点
- 统计术语精确(Pearson卡方/Yates校正/CLR/变异系数)
- 对每个方法交代适用条件与理由,严谨不堆砌

## 6. 评分亮点
- 成分数据特殊处理(定和+CLR)直击数据本质,专业性突出
- 卡方检验前提判断与校正,统计素养高
- 分类与预测均有量化性能指标,结论可信
