# 2015 C题 月上柳梢头,人约黄昏后 提炼稿

## 1. 结构大纲
1. 问题背景(古诗意境)与核心概念定义
   - "月上柳梢头":月亮高度 15°~18°
   - "黄昏后":日没时刻到民用昏影终(太阳高度 0°~-6°)
2. 问题1:建立"人约黄昏后"模型
   - 太阳赤纬模型 → 太阳高度/赤纬/纬度与地方时角的球面三角形关系 → 地方时角模型
3. 建立"月上柳梢头"模型
   - 积日/黄道倾角/月亮黄经黄纬计算 → 月亮赤纬 → 月亮上中天时间模型
4. 模型检验:与已有天文资料对比,误差最大16分钟最小0分钟
5. 问题2:求2016年北京地区两现象发生日期与时间段
6. 结论与讨论

## 2. 摘要写法
- 开篇定义关键概念(月亮高度范围、黄昏后时间定义),让读者立刻抓住建模前提
- 分问题组织:"针对问题1……针对问题2……"
- 突出验证结果数字(误差最大16分钟最小0分钟),证明精度
- 摘要末尾说明模型如何共用:把问题1模型直接输入不同日期纬度求解问题2

## 3. 建模套路
- 机理类 C 题:先精确定义物理概念 → 建立基础天文模型 → 逐层组合成完整模型 → 用真实资料验证
- 善用天文公式链(赤纬→时角→上中天时间),环环相扣
- 用交叉验证替代拟合优度,是机理题的检验方式

## 4. 图表风格
- 球面三角形关系示意图(解释时角/赤纬/高度关系)
- 推算日期与时间段结果表
- 图上公式与几何标注结合

## 5. 语言特点
- 概念先行,先给定义再建模,避免歧义
- 语言凝练专业,不堆砌术语
- 摘要与正文结论一致,数字前后呼应

## 6. 评分亮点
- 核心概念给出可量化定义(15°~18°、0°~-6°),是建模切入点,极有说服力
- 用外部天文资料验证模型,误差量化,可信度高
- 问题1模型直接复用于问题2,体现建模复用思想
