# 2023 C题 蔬菜定价与补货决策 提炼稿

## 1. 结构大纲
1. 问题背景(商超蔬菜凌晨进货、成本加成定价、损耗打折)
2. 问题1:销售规律分析
   - 描述统计(标准差/偏度/峰度)+可视化
   - Spearman相关系数(品类相关性)→ K-means++ 单品分四类(热销/畅销/平销/滞销)
3. 问题2:定价与未来一周补货
   - 成本加成定价与销量的Pearson负相关检验 → 线性回归
   - 时间序列预测未来一周销量 → 利润最大化优化模型(补货量/定价/损耗约束) → 模拟退火求解
   - 结果:最大收益5105.60元
4. 问题3:单品级补货定价
   - 收益最大化优化(29种可售单品,陈列量≥2.5kg约束) → 最大收益1282.2631元
5. 问题4:季度与外部数据建议
   - 灰色关联分析(季节/节气/节日因素)
   - 建议引入客流量/竞品价格/消费者反馈等10种数据
6. 模型讨论与优缺点

## 2. 摘要写法
- 每问一段,先方法后结果,结果给最大收益具体数字
- 方法名全列出(K-means++/模拟退火/灰色关联),体现工具箱丰富度
- 结尾"最后对模型进行了讨论和分析,综合评价了优缺点"——惯例收尾

## 3. 建模套路
- 综合型 C 题标准四件套:统计规律 → 相关/回归 → 时序预测 → 优化决策
- 聚类+回归+预测+优化多模型组合,各司其职
- 优化问题明确目标函数+约束(补货量/定价/损耗),用启发式(模拟退火)求解

## 4. 图表风格
- 品类/单品日销量波动可视化图
- 聚类结果与描述统计表
- 预测结果对比与最优方案表
- 图表都承载数字结论,不空图

- 每问结构固定"针对问题X:先……然后……最后……",节奏感强
- 业务术语与建模术语混排自然(陈列量/补货量/成本加成定价)
- 建议部分结合经济学与经营实际,接地气
