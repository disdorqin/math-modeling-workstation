# 2017 C题 颜色与物质浓度辨识 提炼稿

## 1. 结构大纲
1. 问题背景(颜色读数→物质浓度辨识)
2. 问题1:多元线性回归模型
   - MATLAB Regress 求回归系数与置信区间 → 残差分析
   - 建立判别数据优劣的五大准则:F检验、相关系数R²、P值、估计误差方差S²、数据完整性
   - 数据优劣排序:组胺>溴酸钾>奶中尿素>硫酸铝钾>工业碱
3. 问题2:非线性二次回归模型
   - 线性模型残差大→改用二次回归(rstool)
   - 残差降低两个数量级 → 二次模型更优
4. 问题3:鲁棒性分析
   - 降低颜色维度看对模型的影响
   - 减少数据量看对模型的影响
5. 结论

## 2. 摘要写法
- 先概括总体方法:"通过对……数据进行多元回归分析,建立了线性和非线性回归方程模型,给出评价准则和误差分析"
- 分问题段,每段含方法与关键数字(残差降低两个数量级)
- 问题1直接给出数据优劣排序,结论明确

## 3. 建模套路
- 回归类 C 题经典三件套:拟合 → 评价 → 鲁棒性
- 自己"定义评价准则"是亮点:不仅建模,还建评判标准
- 线性不行就上非线性(二次/残差对比),体现模型选择思维

## 4. 图表风格
- 残差图(判断拟合质量)
- 线性 vs 非线性模型对比表(剩余标准差)
- 评价准则与排序结果表

## 5. 语言特点
- 用统计语言精确(F检验/相关系数/残差/剩余标准差)
- 结论直给("数据优劣的排序为……"),不绕弯

## 6. 评分亮点
- 自定义五大评价准则,把"好坏"量化,逻辑闭环
- 问题2用残差降低两个数量级这种硬数字说服力强
- 问题3做维度与数据量双重鲁棒性分析,模型可信度加分
