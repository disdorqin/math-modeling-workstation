# 线性回归 (linear)

> 卡片来源: 姜启源《数学模型》方法论 + 高教社C题优秀论文真实佐证 · 家族: 回归族 · 关联 task_type: regression

## 适用场景

特征与目标近似线性; 需要可解释的回归系数; 简单基线。判别关键词: 线性关系/趋势外推/成本加成定价与销量关系。

## 核心公式

$$y = w^T x + b + \varepsilon$$

## 建模步骤

1. 数据清洗: 缺失值、异常值处理(可先用散点图看线性趋势)
2. 相关性初检: Pearson 相关系数判断特征与目标是否线性相关
3. 最小二乘拟合: 求解 $\hat w = (X^TX)^{-1}X^Ty$
4. 检验: $R^2$、F 检验、残差分析; 剔除异常点
5. 外推预测并给出置信区间

## C题适用性

适合C题数据回归子问题: 销量与价格关系、放电时间与电压关系、信贷风险评分等。数据条件: 特征少(<10)、样本>特征数、无强共线性。

## 论文佐证

① 2016高教社杯C题「电池剩余放电时间预测」(一等奖): 用二次多项式回归拟合 20-100A 放电曲线,$R^2$均>99%,由电压反推剩余放电时间(系数对 log I 再回归)。② 2018高教社杯C题「大型百货商场会员画像描述」(一等奖): 用一元二次方程拟合激活率-销量关系($R^2=0.7419$)。③ 2020高教社杯C题「银行对中小微企业的信贷决策」(一等奖): 特征提取后以线性回归作为集成模型基分类器之一。

## 易错点

误把非线性当线性; 强共线性致系数爆炸; 外推远超样本范围; 忽略离群点影响。
