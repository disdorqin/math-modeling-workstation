# 微分方程建模 (ode_modeling)

> 卡片来源: 姜启源《数学模型》方法论 + 高教社C题优秀论文真实佐证 · 家族: 机理建模族 · 关联 task_type: differential_equation

## 适用场景

系统演化由机理决定、连续动态。关键词: 增长率/动态系统/传染病/热传导/微分。

## 核心公式

$$\frac{dy}{dt}=f(t,y),\quad y(t_0)=y_0;\quad \text{四阶RK: } y_{n+1}=y_n+\frac{h}{6}(k_1+2k_2+2k_3+k_4)$$

## 建模步骤

1. 明确机理与假设(增长率/反应律)
2. 列微分方程 + 初值条件
3. 解析解或数值解(四阶RK/odeint)
4. 参数拟合(最小二乘校准)
5. 灵敏度分析 + 预测验证

## C题适用性

C题机理动态: 电池放电曲线(实测数据校准)、作物生长、热传导(回焊炉)。

## 论文佐证

① 2016高教社杯C题「电池剩余放电时间预测」(一等奖): 放电曲线本质是机理动态, 论文用多项式拟合还原(与微分方程建模互补)。② 2011高教社杯C题「企业退休职工养老金模型」(九江学院, MATLAB创新奖C题): 用Logistic微分方程 $dy/dt=ay(1-y/y_<built-in function max>)$ 预测职工年平均工资。

## 易错点

机理假设无依据; 参数拟合病态; 数值不稳定(步长不当); 模型复杂化违背「大道至简」。
