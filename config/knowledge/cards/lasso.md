# Lasso回归 (lasso)

> 卡片来源: 姜启源《数学模型》方法论 + 高教社C题优秀论文真实佐证 · 家族: 回归族 · 关联 task_type: regression

## 适用场景

特征较多需自动筛选重要特征、希望稀疏解。关键词: L1正则/特征选择/变量筛选。

## 核心公式

$$\min_w \|y-Xw\|^2 + \alpha\|w\|_1$$

## 建模步骤

1. 标准化特征
2. 用 LassoCV 选 $\alpha$
3. 拟合, 系数被压缩为 0 的为被剔除特征
4. 输出入选特征及其系数, 解释经济含义
5. 可与逐步回归结果对比

## C题适用性

C题指标众多需要降维选变量时(如信贷20+特征筛关键风险变量); 选出特征后再进模型。

## 论文佐证

未在高教社C题获奖论文中作为独立模型出现; 类似思路(特征工程选20个特征后进集成)见 2020高教社杯C题「银行对中小微企业的信贷决策」(一等奖)。

## 易错点

特征强相关时解不稳定(选ridge); 需标准化; $\alpha$ 过大全特征被剔。
