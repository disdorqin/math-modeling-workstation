# 岭回归 (ridge)

> 卡片来源: 姜启源《数学模型》方法论 + 高教社C题优秀论文真实佐证 · 家族: 回归族 · 关联 task_type: regression

## 适用场景

特征强共线(强相关特征对)时缓解回归系数不稳定。关键词: 多重共线性/L2正则/系数收缩。

## 核心公式

$$\min_w \|y-Xw\|^2 + \alpha\|w\|^2$$

## 建模步骤

1. 标准化特征(必须, 否则惩罚失真)
2. 选 $\alpha$: 网格搜索 + 交叉验证(ridgeCV)
3. 拟合求解 $\hat w=(X^TX+\alpha I)^{-1}X^Ty$
4. 与 OLS 对比系数稳定性与 $R^2$
5. 报告系数解读

## C题适用性

C题高相关指标同时作为自变量时(如多个经营指标一起解释销量/风险)使用。

## 论文佐证

未在高教社C题获奖论文中作为独立模型出现; 获奖论文常用 OLS 或 Lasso 型稀疏选择, 岭回归可作为稳健性对比(论文「模型对比」部分)。

## 易错点

未标准化; $\alpha$ 无交叉验证; 期望稀疏解(应换Lasso); 与OLS结果差异大时未解释。
