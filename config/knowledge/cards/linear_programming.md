# 线性规划 (linear_programming)

> 卡片来源: 姜启源《数学模型》方法论 + 高教社C题优秀论文真实佐证 · 家族: 优化族 · 关联 task_type: optimization

## 适用场景

目标与约束均线性, 连续决策变量。关键词: 资源分配/总费用最省/最大收益/约束。

## 核心公式

$$\min c^T x \quad s.t.\ A_{ub}x\le b_{ub},\ A_{eq}x=b_{eq},\ lb\le x\le ub$$

## 建模步骤

1. 设决策变量, 写清单位与取值范围
2. 建目标函数(费用/收益)
3. 列约束: 资源/面积/需求/非负
4. 用 scipy.optimize.linprog 或 Lingo 求解
5. 灵敏度分析(影子价格)

## C题适用性

C题优化核心: 输油管布局、农作物种植方案、信贷额度分配等线性最优化。

## 论文佐证

① 2010高教社杯C题「输油管布置」(西安欧亚学院, 一等奖): 以总费用最省为目标建立线性/优化模型, 用Lingo求解, 最优费用282.7万元。② 2024高教社杯C题「农作物最优种植模型」(C063, 一等奖): 以种植面积线性约束(地块/重茬/豆类轮作)建立最优种植模型, LINGO求解7年最大收益4530万(滞销浪费)或6469万(半价售)。

## 易错点

变量/约束单位混乱; 漏非负约束; 未做灵敏度分析; 把整数问题误当连续问题。
