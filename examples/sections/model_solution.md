# 模型求解

## 求解算法

岭回归的目标函数光滑且严格凸，具有闭式解 $\hat{\boldsymbol{\beta}} = (\tilde{X}^{\top}\tilde{X} + 2n\alpha I)^{-1}\tilde{X}^{\top}\mathbf{y}$，正则化项使待求逆矩阵严格正定，从根本上消除了共线性导致的病态。Lasso 的 $L_1$ 项在原点不可导，采用坐标下降法迭代求解：每轮固定其余分量、对单个 $\beta_j$ 做软阈值更新，直至系数变化小于收敛容差。集成模型分别用装袋法与前向分步梯度提升训练。

## 训练与验证协议

为保证候选模型可比，所有模型共用一套固定的求解与验证协议：

- 特征标准化与模型拟合封装在同一管道内，标准化参数只在训练折上估计，避免验证折信息泄漏；
- 采用五折交叉验证，折划分由固定随机种子生成，所有候选模型使用完全相同的划分；
- 每折分别计算均方根误差、平均绝对误差与决定系数，再对折取均值与标准差；
- 全部超参数、随机种子与执行环境随实验一并登记，保证结果可复现。

## 求解结果与模型选择

在上述协议下完成五个候选模型的训练与交叉验证。以主指标均值排序，正则化线性模型位居前列，两类树集成模型明显落后；在三个线性模型内部，Lasso 不仅主指标均值最优，折间标准差也最小，因此按既定准则被选为最终模型 [claim-4d802d59f904]。各模型的交叉验证表现对比见图 [figure-8c0270f7257b]。

在全样本上重新拟合所选模型，其系数结构印证了数据分析阶段的诊断：体质指数与血清甘油三酯对数值获得最大的正向系数，平均动脉压次之；而共线特征组内的冗余成分被 $L_1$ 惩罚精确置零，实现了自动特征筛选。这一结果给出了子问题一所要求的特征子集，且该子集是由模型在验证协议下自行确定的，而非人工预先删除。
