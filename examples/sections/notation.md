# 符号说明

| 符号 | 含义 | 说明 |
|---|---|---|
| $n$ | 样本量 | 参与建模的患者例数 |
| $p$ | 特征维数 | 基线特征个数 |
| $\mathbf{x}_i \in \mathbb{R}^{p}$ | 第 $i$ 例患者的基线特征向量 | 含年龄、性别、体质指数、平均动脉压与六项血清学指标 |
| $y_i \in \mathbb{R}$ | 第 $i$ 例患者一年后的病情进展指数 | 目标变量 |
| $\tilde{\mathbf{x}}_i$ | 标准化后的特征向量 | 各分量零均值、单位方差 |
| $\boldsymbol{\beta} \in \mathbb{R}^{p}$ | 回归系数向量 | 分量 $\beta_j$ 表示特征 $j$ 的边际作用 |
| $\beta_0$ | 截距项 | 标准化后等于目标变量均值 |
| $\alpha$ | 正则化强度 | 控制系数收缩幅度的超参数 |
| $\hat{y}_i$ | 模型对第 $i$ 例的预测值 | |
| $K$ | 交叉验证折数 | |
| $\mathcal{D}_k$ | 第 $k$ 折的验证子集 | |
| $\rho_{jl}$ | 特征 $j$ 与特征 $l$ 的 Pearson 相关系数 | 用于诊断多重共线性 |
| $\text{RMSE}$ | 均方根误差 | 主评价指标 |
| $\text{MAE}$ | 平均绝对误差 | 辅助评价指标 |
| $R^2$ | 决定系数 | 解释方差比例 |
| $q_{1/3}, q_{2/3}$ | 预测值的三分位点 | 风险分层阈值 |

变量与目标的对应关系为：以 $\tilde{\mathbf{x}}_i$ 为自变量、$y_i$ 为因变量，求解使正则化损失最小的系数向量 $\boldsymbol{\beta}$。
