# 赛题：慢性疾病一年期病情进展的量化建模与风险分层

## 背景

慢性代谢性疾病的管理高度依赖对"病情进展速度"的早期判断。临床上常在基线时点采集患者的人口学指标、体格指标与血清学指标，并在一年后测量一个综合病情进展指数（progression index）。若能在基线时点即给出该指数的可靠预测，医院即可把有限的随访与干预资源优先分配给高风险人群。

本题使用一份公开的真实临床观测数据（Efron, Hastie, Johnstone & Tibshirani, "Least Angle Regression", *Annals of Statistics*, 2004；亦为 scikit-learn 内置 `load_diabetes` 数据集的未标准化原始版本），共 442 名患者、10 个基线特征与 1 个一年后测得的病情进展指数。

## 数据说明

文件 `diabetes_real.csv`，442 行 × 11 列：

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| age | 年龄 | 岁 |
| sex | 性别编码 | 1 / 2 |
| bmi | 体质指数 | kg/m² |
| bp | 平均动脉压 | mmHg |
| s1 | 总血清胆固醇 TC | mg/dL |
| s2 | 低密度脂蛋白 LDL | mg/dL |
| s3 | 高密度脂蛋白 HDL | mg/dL |
| s4 | 总胆固醇/HDL 比值 TCH | 比值 |
| s5 | 血清甘油三酯对数值 LTG | log(mg/dL) |
| s6 | 血糖 GLU | mg/dL |
| progression | 一年后病情进展指数（目标变量） | 无量纲，25–346 |

数据为横截面观测数据，无时间序列结构，无缺失值。样本量 442，特征数 10，属于典型的小样本、强共线性回归场景（s1 与 s2 之间、s3 与 s4 之间存在明确的生理学共线性）。

## 待解决问题

**问题一（数据理解与特征筛选）**
对基线特征进行探索性分析，刻画各特征的分布、异常值与相互间的相关结构。识别存在多重共线性的特征组，并给出可用于后续建模的特征子集及其筛选依据。

**问题二（病情进展预测模型）**
建立由 10 个基线特征预测一年后 progression 的数学模型。要求：
1. 至少比较三类模型（如普通最小二乘、带正则化的线性模型、非线性/集成模型）；
2. 采用交叉验证给出可比较的泛化误差估计（R²、RMSE、MAE）；
3. 说明模型选择的准则，并解释所选模型中各特征的作用方向与相对重要性。

**问题三（稳健性与风险分层）**
1. 对所选模型进行敏感性分析：考察超参数、随机划分种子与特征子集变化对模型性能的影响，说明结论的稳健区间；
2. 依据模型预测值将患者划分为低、中、高三档风险人群，给出分层阈值及其依据；
3. 讨论模型的适用边界：在何种人群、何种取值范围之外，模型结论不再可靠。
