# 蒙特卡洛模拟

## 适用场景

输入含随机性、需要估计输出分布或风险概率的场景：利润/成本风险分析、库存缺货概率、工程可靠性评估、政策情景模拟。

## 不适用场景

- 系统无随机性或已有解析解（直接计算更精确）。
- 单次模拟时间极长而迭代次数需求很大（需高性能计算）。
- 参数分布完全未知时，设定错误分布会导致结果严重偏差。

## 输入要求

- 随机变量的概率分布（均值、标准差、类型：正态/均匀/指数等）。
- 目标函数 f(x)：由随机输入计算输出。
- 迭代次数 N（通常 ≥ 1000，精度要求高时 ≥ 10000）。
- 随机种子（保证可复现）。

## 核心原理

**大数定律**：N → ∞ 时，样本均值收敛到期望值：

```
(1/N) sum_{i=1}^{N} f(X_i) → E[f(X)]
```

**估计标准误差**：

```
SE = σ_f / sqrt(N)
```

N 增大 4 倍，误差减半（收敛慢，需大样本）。

## 基本流程

```
1. 确定输入随机变量 X = (X₁, X₂, ..., Xₖ) 及其分布
2. for i = 1 to N:
       从分布中采样 x_i
       计算输出 y_i = f(x_i)
3. 统计 y 的分布：均值、标准差、分位数
4. 估计目标概率：P(y < threshold) = count(y_i < threshold) / N
```

## 关键统计输出

| 输出 | 含义 |
|---|---|
| 均值 E[y] | 期望输出 |
| 标准差 σ_y | 输出波动范围 |
| P5 / P95 | 90% 置信区间 |
| P(y < 0) | 亏损/失败概率 |

## 收敛性验证

绘制"迭代次数 vs 估计均值"曲线，观察趋于平稳的迭代数作为参考。

## 论文表达模板

```
本文采用蒙特卡洛模拟对[目标]进行风险分析。
[变量名]服从正态分布 N([均值], [标准差]²)，
[变量名]服从均匀分布 U([a], [b])（分布假设来源：[数据/文献/专家]）。
以固定随机种子保证可复现，迭代 N = [值] 次。
仿真结果：期望[输出] = [值]，标准差 = [值]，
90% 置信区间为 [[P5], [P95]]，
[亏损/失败]概率 P(y < 0) = [值]%（需用户核验分布假设后引用）。
```

## 常见错误

- 分布假设无依据（凭感觉设定均值/标准差）。
- 迭代次数过少（< 500），结果不稳定。
- 未设置随机种子，结果不可复现。
- 把 P5/P95 当作最坏/最好情况（极端值需更多迭代或极值理论）。
- 忽略输入变量间的相关性（独立采样高估多元随机性）。

## 检查清单

- [ ] 输入变量分布假设是否有数据或文献支撑。
- [ ] 随机种子是否固定并记录（可复现）。
- [ ] 迭代次数是否经过收敛性验证（均值趋于稳定）。
- [ ] 是否报告均值、标准差、关键分位数。
- [ ] 输入变量之间是否存在相关性，若有是否考虑联合分布。
- [ ] 结论是否注明"结果依赖分布假设，假设偏差会导致结果偏差"。
