# 聚类模型

## 适用场景

无标签数据分组、模式发现、用户画像分层、区域划分、异常检测（DBSCAN）。数据本身没有预定类别，需要从相似性发现自然分组。

## 不适用场景

- 已有标签，目标是预测类别（用分类模型）。
- 业务上群体数量已知且有含义（直接按规则分组）。
- 数据维度极高且不经降维（聚类距离失效）。

## 输入要求

- 特征矩阵 X（n × p），数值型，无缺失，建议先标准化。
- K-Means：需预定簇数 k；DBSCAN：需设定邻域半径 ε 和最少样本数 min_samples。
- 样本量 ≥ 3 × k（K-Means），或 ≥ min_samples（DBSCAN）。

## 核心公式

### K-Means

目标：最小化簇内方差（Inertia）

```
min_C  sum_{k=1}^{K} sum_{x ∈ C_k} ||x - μ_k||²
```

迭代步骤：
1. 随机初始化 K 个中心 μ_1, ..., μ_K
2. 分配：每个点归属最近中心
3. 更新：μ_k = mean(C_k)
4. 重复直到中心不再变化

**肘部法则选 K**：绘制 Inertia vs K，选拐点处。

### DBSCAN

- 核心点：ε 邻域内样本数 ≥ min_samples
- 边界点：在核心点邻域内但自身不是核心点
- 噪声点（标签 = -1）：不属于任何簇

优点：形状任意、自动识别噪声；缺点：ε 和 min_samples 敏感。

### 评价指标

| 指标 | 公式/含义 | 范围 |
|---|---|---|
| 轮廓系数 Silhouette | (b - a) / max(a, b)，a=簇内距离，b=最近他簇距离 | [-1, 1]，越大越好 |
| Davies-Bouldin | 簇间/簇内距离比值均值 | 越小越好 |
| Inertia | 簇内平方和（K-Means 内部指标） | 越小越好 |

## 论文表达模板

```
本文对 n 个样本采用[K-Means/DBSCAN]聚类，
特征经 Z-score 标准化后，[以 PCA 降至 2 维可视化/直接聚类]。
[K-Means：通过肘部法则确定 k = [值]；]
[DBSCAN：通过 k 距离图确定 ε = [值]，min_samples = [值]；]
最终分为 [k] 个簇，轮廓系数为 [值]。
簇 1 特征为[描述]，簇 2 特征为[描述]（需结合业务解释，不可只报告编号）。
```

## 常见错误

- 特征未标准化，大量纲指标主导距离计算。
- K-Means 中 k 凭感觉设定，未用肘部法则或轮廓系数验证。
- 把聚类编号当作固定标签（多次运行 K-Means 编号会变）。
- 不报告轮廓系数，无法判断聚类质量好坏。
- 高维数据未降维，距离集中失效。

## 检查清单

- [ ] 特征是否标准化（消除量纲）。
- [ ] k 或 ε / min_samples 是否有客观依据（肘部图、k 距离图）。
- [ ] 轮廓系数是否 > 0.3（经验阈值，低于此考虑调整参数）。
- [ ] 是否用 PCA 或 t-SNE 可视化确认簇的分离情况。
- [ ] 聚类结果是否有业务解释（不仅报告数字）。
- [ ] 结论是否注明"聚类结果依赖特征选择和参数设置，需结合业务验证"。
