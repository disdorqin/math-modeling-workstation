# TOPSIS

## 适用场景

多指标评价排序：对象需要根据与理想解的距离排序，指标有明确方向（正向/负向），权重已知或可由熵权法确定。

## 不适用场景

- 指标方向不清、权重无依据。
- 指标间存在强相关（建议先做 PCA 或灰色关联降维）。
- 对象数量极少（< 3 个）时结果缺乏区分力。

## 输入要求

- 评价矩阵：n 个对象 × m 个指标，均为数值型，无缺失。
- 指标方向：每个指标标注 positive（越大越好）或 negative（越小越好）。
- 权重向量：非负，和为 1（可由熵权法或 AHP 确定）。

## 核心公式

**第一步：归一化**

正向指标：

```
r_ij = (x_ij - x_j_min) / (x_j_max - x_j_min)
```

负向指标：

```
r_ij = (x_j_max - x_ij) / (x_j_max - x_j_min)
```

**第二步：加权归一化**

```
v_ij = w_j * r_ij / sqrt(sum_i(r_ij^2))
```

**第三步：确定正负理想解**

```
V+ = (max_i(v_ij) for each j)   # 正理想解
V- = (min_i(v_ij) for each j)   # 负理想解
```

**第四步：计算距离**

```
D+_i = sqrt(sum_j (v_ij - V+_j)^2)
D-_i = sqrt(sum_j (v_ij - V-_j)^2)
```

**第五步：计算贴近度（综合得分）**

```
C_i = D-_i / (D+_i + D-_i)      # C_i ∈ [0, 1]，越大越优
```

## 常见变体

- **熵权-TOPSIS**：用熵权法自动确定 w_j，减少主观性。
- **加权标准化 TOPSIS**：先做向量归一化再加权，适合量纲差异大的指标。
- **模糊 TOPSIS**：指标值为模糊数，适合专家打分数据。

## 论文表达模板

```
本文构建了包含 m 个指标的评价体系，采用 TOPSIS 方法对 n 个评价对象进行综合排序。
首先对原始数据进行正向化处理，其中[正向指标]取越大越好，[负向指标]取越小越好；
随后通过向量归一化消除量纲影响，以[权重来源]确定各指标权重；
最终计算各对象与正负理想解的欧氏距离，得到贴近度 C_i，按 C_i 降序排名。
结果显示[用户核验后的排名结论]（需经数据和参数核验后引用）。
```

## 常见错误

- 正负向指标混淆导致排名颠倒。
- 权重来源未说明，可解释性差。
- 未检查指标量纲差异，直接加权导致大数值指标主导结果。
- 把贴近度 C_i 当作绝对得分（如"得分 0.85 意味着优秀"），实为相对排名指标。

## 检查清单

- [ ] 指标方向是否全部正确标注。
- [ ] 权重是否非负且和为 1，来源是否说明。
- [ ] 是否存在全等列（max = min），脚本已处理为 1，需说明含义。
- [ ] 贴近度是否全部在 [0, 1] 之间，有无 NaN。
- [ ] 敏感性：权重扰动 ±10% 后排名是否稳定。
- [ ] 结论是否注明"仅基于当前数据和权重设置，需用户核验"。
