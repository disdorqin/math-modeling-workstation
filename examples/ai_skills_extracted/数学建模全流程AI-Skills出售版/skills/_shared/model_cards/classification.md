# 分类模型

## 适用场景

有已知类别标签、需要预测类别归属的场景：风险等级判断、故障诊断、客户分群（有标签）、文本/图像类别识别。

## 不适用场景

- 标签缺失或标签质量不可信。
- 类别极度不平衡且无法重采样（考虑代价敏感学习）。
- 需要无监督发现群体（用聚类模型）。

## 输入要求

- 特征矩阵 X（n × p）和类别标签向量 y，均无缺失。
- 每类样本量建议 ≥ 10，总样本 ≥ 6p。
- 特征为数值型（类别型需编码）。

## 常用模型对比

| 模型 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 逻辑回归 | 可解释，概率输出 | 仅线性边界 | 需要系数解释 |
| 决策树 | 可视化，无需标准化 | 易过拟合 | 规则提取 |
| 随机森林 | 稳健，特征重要性 | 黑盒 | 中小规模数据 |
| SVM | 高维有效 | 慢，参数敏感 | 文本、图像特征 |

## 核心公式

### 逻辑回归

```
P(y=1|x) = 1 / (1 + exp(-(β₀ + β^T x)))
```

决策边界：`P(y=1|x) ≥ 0.5`（阈值可调）

目标函数（最大化对数似然）：

```
L(β) = sum_i [y_i log(p_i) + (1-y_i) log(1-p_i)]
```

### 评价指标

混淆矩阵定义：TP / FP / FN / TN

```
精确率 Precision = TP / (TP + FP)
召回率 Recall    = TP / (TP + FN)
F1 Score         = 2 * P * R / (P + R)
准确率 Accuracy  = (TP + TN) / (TP + FP + FN + TN)
```

不平衡类别优先用 **F1** 或 **AUC-ROC**，不用 Accuracy。

## 论文表达模板

```
本文以[类别标签]为目标，选取[特征列表]构建分类模型。
数据以[比例]划分训练集和测试集，特征经标准化处理后，
训练[逻辑回归/决策树/随机森林/SVM]分类器。
模型在测试集上的准确率为[值]，F1 = [值]（宏平均）。
混淆矩阵见图 X，[类别名]的召回率为[值]，
表明模型对[类别]的识别能力[较好/有待提升]。
（上述结果依赖测试集分割，建议交叉验证后引用。）
```

## 常见错误

- 只报告 Accuracy，忽略类别不平衡导致的虚假高分。
- 用训练集指标评估，未做测试集评估。
- 阈值固定为 0.5 而不根据业务目标调整（高召回/高精确场景）。
- 未检查特征泄漏（标签信息提前进入特征）。

## 检查清单

- [ ] 类别分布是否均衡，不平衡时是否说明处理方式。
- [ ] 评价指标是否选对（不平衡用 F1/AUC，平衡可用 Accuracy）。
- [ ] 是否在独立测试集（或交叉验证）上评估，未用训练集。
- [ ] 特征是否标准化（逻辑回归/SVM 需要）。
- [ ] 混淆矩阵中各类别的误分类是否符合业务可接受范围。
- [ ] 结论是否注明"基于当前数据分布，新数据需重新评估"。
