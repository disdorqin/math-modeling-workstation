# 回归模型

## 适用场景

有连续目标变量、需要量化解释变量影响或进行外推预测的场景：销量预测、成本估算、影响因素分析、参数拟合。

## 不适用场景

- 目标变量为类别（用分类模型）。
- 特征与目标存在明显非线性且无法变换（考虑树模型或非线性回归）。
- 样本量 < 特征数（需正则化或降维）。

## 输入要求

- 特征矩阵 X（n × p）和目标向量 y（n × 1），均为数值型，无缺失。
- 建议 n ≥ 5p 以保证参数估计稳定（OLS）。
- 特征与目标之间存在线性（或可线性化）关系。

## 核心公式

### 普通最小二乘（OLS）

目标：最小化残差平方和

```
min ||y - Xβ||²
```

解析解：

```
β̂ = (X^T X)^{-1} X^T y
```

预测：`ŷ = X β̂`

### Ridge 回归（L2 正则）

```
β̂_ridge = (X^T X + λI)^{-1} X^T y
```

适合特征高度共线或 p 接近 n 时。

### Lasso 回归（L1 正则）

```
min ||y - Xβ||² + λ||β||₁
```

L1 惩罚会产生稀疏解，自动做特征选择。

## 关键评价指标

| 指标 | 公式 | 含义 |
|---|---|---|
| MAE | mean(\|y - ŷ\|) | 平均绝对误差 |
| RMSE | sqrt(mean((y - ŷ)²)) | 均方根误差，对大误差更敏感 |
| R² | 1 - SS_res/SS_tot | 拟合优度，越接近 1 越好 |
| 调整 R² | 1 - (1-R²)(n-1)/(n-p-1) | 惩罚多余特征 |

## 假设检验（OLS）

- **线性性**：绘制残差 vs 拟合值，无明显趋势。
- **同方差性**：残差方差不随 ŷ 变化。
- **正态性**：残差 QQ 图接近直线。
- **无多重共线性**：VIF < 10。

## 常见错误

- 特征未标准化直接比较系数大小（量纲不同时系数不可比）。
- R² 高不等于预测有效（训练集过拟合）。
- 未做残差诊断，违反 OLS 假设仍报告显著性。
- 外推超出训练数据范围而不说明风险。

## 检查清单

- [ ] 是否检查特征与目标的散点图，确认线性关系。
- [ ] 是否有多重共线性（VIF 或相关矩阵）。
- [ ] 训练/测试分割比例是否合理，结果是否在测试集上评估。
- [ ] 残差是否随机分布（无明显趋势、无异方差）。
- [ ] 正则化系数 λ 是否通过交叉验证选取。
- [ ] 结论是否注明"仅基于当前数据，外推需谨慎"。
