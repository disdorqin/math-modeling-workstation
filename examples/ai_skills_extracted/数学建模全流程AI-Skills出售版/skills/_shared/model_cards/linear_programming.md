# 线性规划

## 适用场景

目标函数和所有约束均为线性、决策变量连续的资源分配、排产、配送和调度问题。

## 不适用场景

- 目标或约束含非线性项（乘积、指数、绝对值等），需用非线性规划。
- 决策变量必须取整数（用整数规划）。
- 约束数量极多、变量规模极大时需专业优化器（Gurobi、CPLEX）。

## 标准形式

**最小化（或最大化）**

```
min  c^T x
s.t. A_ub x ≤ b_ub          （不等式约束）
     A_eq x = b_eq          （等式约束）
     lb ≤ x ≤ ub            （变量边界）
```

**最大化转换**：max f(x) ↔ min −f(x)

## 建模步骤

1. **定义决策变量** x = (x₁, x₂, ..., xₙ)，明确业务含义和单位。
2. **写目标函数**：确认是最大化（利润、效率）还是最小化（成本、时间）。
3. **列约束条件**：资源上限、需求下限、平衡条件、非负约束。
4. **检查线性性**：系数矩阵 A 和向量 b、c 均为常数。
5. **求解**：Python 用 `scipy.optimize.linprog`（HiGHS 求解器）。
6. **灵敏度分析**：扰动 b 或 c ±10%，检验最优解稳定性。

## 对偶理论与影子价格

对偶问题：

```
max  b^T y
s.t. A^T y ≤ c
     y ≥ 0
```

**影子价格**（对偶变量 y*）：约束右端增加 1 单位，目标函数变化量。影子价格为 0 表示该约束不紧（冗余）。

## 论文表达模板

```
本文建立线性规划模型，以[目标]为优化目标，
决策变量为[变量列表及含义]。
约束包括[资源约束/需求约束/非负约束]（共 m 个）。
使用 HiGHS 求解器求得最优解：[x* = (值列表)]，
目标函数值为 [值]。
敏感性分析表明，当[约束名称]右端增加 1 单位时，
目标函数改善 [影子价格] 单位（需用户结合实际资源可调整性判断）。
```

## 常见错误

- 变量定义不明确（缺单位或业务含义）。
- 约束方向写反（≤ 写成 ≥），导致可行域错误。
- 未检查问题是否有界（无界时求解器报错，需加上限约束）。
- 只报告最优值，不分析决策变量取值的业务含义。

## 检查清单

- [ ] 所有变量是否有明确定义和单位。
- [ ] 约束是否覆盖所有资源限制和需求下限。
- [ ] 求解状态是否为成功（`Success: True`）。
- [ ] 最优解是否满足全部约束（代入验证）。
- [ ] 是否计算影子价格，说明哪个约束最紧。
- [ ] 结论是否注明"结果依赖参数取值，实际执行前需核验数据"。
