# 时间序列模型

## 适用场景

按时间顺序记录的数据预测：销量、流量、价格、气温等的趋势外推和短期预测。重点适合数据量 ≥ 15 个时间点、具备一定规律性的序列。

## 不适用场景

- 时间顺序不可靠或时间间隔不规律。
- 序列极短（< 6 个点），推荐 GM(1,1)。
- 外部冲击主导变化（如政策突变），模型假设失效。

## 常用模型对比

| 模型 | 适用 | 特点 |
|---|---|---|
| 移动平均（MA） | 平稳序列、平滑噪声 | 简单，无参数估计 |
| 指数平滑（ES） | 有趋势的平稳序列 | α 权衡近期 vs 历史 |
| ARIMA(p,d,q) | 平稳/差分平稳序列 | 统计严谨，需调参 |
| Holt-Winters | 含趋势 + 季节性 | 三参数，季节性强 |

## 核心公式

### 移动平均（窗口 w）

```
ŷ(t) = (1/w) * sum_{i=1}^{w} y(t-i)
```

### 指数平滑（平滑系数 α ∈ (0,1]）

```
ŷ(t) = α * y(t-1) + (1-α) * ŷ(t-1)
```

α 越大，近期数据权重越高；α 越小，历史数据影响越大。

### ARIMA(p, d, q)

差分 d 次使序列平稳，再建模：

```
φ(B) Δ^d y(t) = θ(B) ε(t)

AR(p)：y(t) = φ₁y(t-1) + ... + φₚy(t-p) + ε(t)
MA(q)：y(t) = ε(t) - θ₁ε(t-1) - ... - θ_q ε(t-q)
```

参数选择：ACF/PACF 图，或 AIC/BIC 最小化。

### 平稳性检验（ADF 检验）

H₀：序列含单位根（非平稳）。p-value < 0.05 则拒绝 H₀，认为平稳。

### 预测误差

| 指标 | 公式 |
|---|---|
| MAE | mean(\|y - ŷ\|) |
| RMSE | sqrt(mean((y - ŷ)²)) |
| MAPE | mean(\|y - ŷ\| / \|y\|) × 100% |

## 论文表达模板

```
本文对[变量名]的[时间范围]序列（共 n 个观测值）建立时间序列预测模型。
ADF 检验结果（p = [值]）表明序列[平稳/经 d 阶差分后平稳]。
通过 ACF/PACF 图确定 ARIMA([p],[d],[q]) 模型，
[或：采用指数平滑，α = [值]（通过 RMSE 最小化确定）。]
模型在测试集（后 [比例] 数据）的 MAPE = [值]%，RMSE = [值]。
预测未来 [h] 期结果为 [数值]（需结合最新数据更新模型后使用）。
```

## 常见错误

- 未检验平稳性，直接对非平稳序列建 ARIMA。
- 训练/测试集时序割裂（测试集不能用未来数据）。
- MAPE 在 y 接近零时失效（分母趋零）。
- 预测区间过长（超过序列长度的 50%），误差累积失控。

## 检查清单

- [ ] 序列是否平稳（ADF 检验），非平稳时是否差分处理。
- [ ] ACF/PACF 图是否用于确定 p、q 阶数。
- [ ] 模型残差是否通过白噪声检验（Ljung-Box test）。
- [ ] 测试集是否严格在训练集之后（无数据泄漏）。
- [ ] 预测误差是否报告（MAE/RMSE/MAPE）。
- [ ] 结论是否注明"预测区间随预测期延长而增大，长期预测需谨慎"。
