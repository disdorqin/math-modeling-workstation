# GM(1,1) 灰色预测模型

## 适用场景

样本量少（4–20 个数据点）、序列单调递增、适合短期趋势外推的场景，如年度统计数据、小样本消耗量、政策效果预测。

## 不适用场景

- 序列含负数或零（GM 要求全正序列）。
- 序列波动剧烈、非单调。
- 数据量充足（> 30 个点）时，统计回归和时间序列方法通常更优。
- 需要区间预测或置信区间时（GM 不直接给出不确定性估计）。

## 输入要求

- 原始序列 X⁰ = (x⁰(1), x⁰(2), ..., x⁰(n))，n ≥ 4，全正。
- 预测期数 periods ≥ 1。

## 核心公式

**第一步：一阶累加（AGO）生成序列**

```
X¹(k) = sum_{i=1}^{k} x⁰(i)
```

**第二步：紧邻均值序列（背景值）**

```
Z¹(k) = 0.5 * (X¹(k) + X¹(k-1)),  k = 2, 3, ..., n
```

**第三步：建立灰微分方程，用最小二乘估计参数**

方程：`x⁰(k) + a * Z¹(k) = b`

矩阵形式：

```
[a, b]^T = (B^T B)^{-1} B^T Y

其中 B = [-Z¹(2), 1; -Z¹(3), 1; ...; -Z¹(n), 1]
     Y = [x⁰(2), x⁰(3), ..., x⁰(n)]^T
```

**第四步：白化响应函数（连续解离散化）**

```
X̂¹(k+1) = (x⁰(1) - b/a) * exp(-a*k) + b/a
```

**第五步：IAGO 还原**

```
x̂⁰(1) = x⁰(1)
x̂⁰(k) = X̂¹(k) - X̂¹(k-1),  k = 2, 3, ...
```

## 精度检验

| 相对误差均值 | 精度等级 |
|---|---|
| < 1% | 优 |
| 1%–5% | 良 |
| 5%–10% | 合格 |
| > 10% | 需考虑其他模型 |

后验差比值 C = S₂/S₁ < 0.35 为优，< 0.50 为良。

## 论文表达模板

```
本文对[变量名]的历史序列（共 n 个观测值）建立 GM(1,1) 灰色预测模型。
原始序列经一阶累加生成后，通过最小二乘法估计发展系数 a = [值] 和灰色作用量 b = [值]。
模型对训练期的平均相对误差为 [值]%，后验差比值 C = [值]，精度等级为[等级]。
预测未来 [periods] 期的结果为 [数值]（需经数据核验后引用）。
```

## 常见错误

- 原始序列含零或负数，未做平移处理。
- 数据量过多（> 20）仍用 GM，拟合误差累积。
- 直接报告预测值而未做精度检验。
- 混淆 a 的符号：a > 0 表示衰减，a < 0 表示增长。

## 检查清单

- [ ] 序列是否全正，长度 ≥ 4。
- [ ] 参数 a 和 b 是否符合业务认知（增长/衰减方向）。
- [ ] 训练期平均相对误差是否已计算并报告。
- [ ] 预测期数是否合理（通常不超过原始序列长度的 50%）。
- [ ] 结论是否标注"短期外推，建议核验最新数据后使用"。
