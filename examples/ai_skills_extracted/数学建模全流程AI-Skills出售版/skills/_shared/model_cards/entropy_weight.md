# 熵权法

## 适用场景

多指标评价中用数据本身的离散程度客观确定权重，避免主观赋权偏差。常与 TOPSIS 组合使用（熵权-TOPSIS）。

## 不适用场景

- 样本量过少（< 5 个对象），离散度统计不可靠。
- 某指标所有样本值完全相同（熵最大，权重趋零，但该指标可能业务上仍重要）。
- 指标离散度不代表重要性的场景（需结合主观判断或 AHP 修正）。

## 输入要求

- 评价矩阵：n 个对象 × m 个指标，均为数值型，无缺失。
- 指标方向：每个指标标注 positive（越大越好）或 negative（越小越好）。

## 核心公式

**第一步：正向化归一化**

正向指标：

```
r_ij = (x_ij - x_j_min) / (x_j_max - x_j_min)
```

负向指标：

```
r_ij = (x_j_max - x_ij) / (x_j_max - x_j_min)
```

加微小量 ε（通常 1e-12）避免 log(0)：`p_ij = (r_ij + ε) / sum_i(r_ij + ε)`

**第二步：计算第 j 个指标的信息熵**

```
e_j = -k * sum_i (p_ij * ln(p_ij)),   k = 1 / ln(n)

e_j ∈ [0, 1]，越小表示该指标区分能力越强
```

**第三步：计算差异系数（多样性）**

```
d_j = 1 - e_j
```

**第四步：归一化得到权重**

```
w_j = d_j / sum_j d_j
```

## 与主观赋权的组合

| 方式 | 适用 |
|---|---|
| 纯熵权 | 数据驱动，指标间差异明显 |
| 纯 AHP | 主观专家判断，缺乏数据 |
| 熵权 + AHP 加权平均 | 兼顾客观数据与专家经验 |

## 论文表达模板

```
本文采用熵权法对 m 个评价指标进行客观赋权。
首先对原始数据进行正向化处理，消除量纲影响；
计算各指标的信息熵 e_j，再由差异系数 d_j = 1 - e_j 归一化得到权重向量 w。
权重最高的指标为[指标名]（w = [值]），说明该指标在样本间差异最大，对综合排名影响最显著。
（权重依赖样本分布，增减样本会导致权重变化，需用户结合业务判断后使用。）
```

## 常见错误

- 未正向化直接计算熵，负向指标方向错误导致排名颠倒。
- 未添加微小量 ε，导致 ln(0) 数值溢出。
- 样本 < 5 时仍用熵权，权重受单个异常值影响极大。
- 把权重趋零的指标直接删除，未说明业务含义。

## 检查清单

- [ ] 指标方向是否全部正确标注。
- [ ] 是否有全等列（max = min），对应权重为 0，需说明处理方式。
- [ ] 权重和是否为 1，有无 NaN 或负值。
- [ ] 样本量是否 ≥ 5。
- [ ] 是否做了敏感性分析（去掉某个样本后权重变化是否合理）。
- [ ] 结论是否注明"客观权重依赖样本，建议与主观判断交叉验证"。
