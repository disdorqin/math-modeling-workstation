# 灰色关联分析（GRA）

## 适用场景

小样本（4–20 个对象）、多序列相似性量化、影响因素排序、比较对象与参考序列的接近程度。常用于找出与目标变量最相关的指标。

## 不适用场景

- 参考序列没有合理业务含义。
- 序列长度差异极大或存在大量缺失值。
- 样本量充足（> 30）时，Pearson 或 Spearman 相关系数解释更强。

## 输入要求

- 参考序列 X₀ = (x₀(1), x₀(2), ..., x₀(n))：目标变量或理想标准。
- 比较序列 X_i = (x_i(1), x_i(2), ..., x_i(n))：待分析的影响因素。
- 分辨系数 ρ ∈ (0, 1]，通常取 0.5。

## 核心公式

**第一步：无量纲化（初值化或均值化）**

```
x̃_i(k) = x_i(k) / x_i(1)        （初值化）
或
x̃_i(k) = x_i(k) / mean(X_i)     （均值化）
```

**第二步：计算差序列**

```
Δ_i(k) = |x̃₀(k) - x̃_i(k)|
```

**第三步：计算两极差**

```
Δ_min = min_i min_k Δ_i(k)
Δ_max = max_i max_k Δ_i(k)
```

**第四步：计算灰色关联系数**

```
γ_i(k) = (Δ_min + ρ Δ_max) / (Δ_i(k) + ρ Δ_max)

γ_i(k) ∈ (0, 1]，越接近 1 表示在该时刻与参考序列越接近
```

**第五步：计算灰色关联度（平均）**

```
r_i = (1/n) sum_{k=1}^{n} γ_i(k)
```

r_i 越大，比较序列 X_i 与参考序列 X₀ 的关联度越高。

## 分辨系数 ρ 的影响

- ρ 越小，关联系数差异越大（分辨力强）。
- ρ 越大，关联系数趋于均等（分辨力弱）。
- 通常取 ρ = 0.5，如需更强区分可用 ρ = 0.1–0.3。

## 论文表达模板

```
本文以[目标变量]为参考序列，对[n]个比较序列进行灰色关联分析。
数据经均值化处理后，取分辨系数 ρ = 0.5，
计算各比较序列与参考序列的灰色关联度。
结果显示[变量名]的关联度最高（r = [值]），
表明其与[目标]的变化趋势最为一致，
而[变量名]关联度最低（r = [值]）（结论需结合数据来源核验）。
```

## 常见错误

- 未无量纲化直接计算，量纲不同时差序列失真。
- ρ 选取随意，不说明依据或不做敏感性分析。
- 把关联度最高误解为"因果关系"（GRA 只反映趋势相似性）。
- 样本数 n < 4 时关联度计算结果不稳定。

## 检查清单

- [ ] 参考序列是否有明确业务含义。
- [ ] 是否进行无量纲化处理（初值化或均值化）。
- [ ] ρ 取值是否说明，是否做 ρ 变化的敏感性分析。
- [ ] 关联度差异是否足够显著（< 0.1 差异意义不大）。
- [ ] 结论是否区分"趋势相关"与"因果关系"。
- [ ] 结论是否注明"需配合业务知识解释，不可直接作为因果推断依据"。
