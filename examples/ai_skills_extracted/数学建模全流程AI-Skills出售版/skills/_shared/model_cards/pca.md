# PCA 主成分分析

## 适用场景

高维指标降维、消除多重共线性、综合评价得分、可视化（降至 2D/3D）、作为其他模型的前处理步骤。

## 不适用场景

- 指标解释性要求极高（PCA 主成分是原始指标的线性组合，含义不直观）。
- 数据明显非线性结构（考虑 t-SNE、UMAP）。
- 样本量 n < 特征数 p（协方差矩阵不满秩）。

## 输入要求

- 数值矩阵 X（n × p），建议先标准化（Z-score）消除量纲影响。
- 各指标之间存在一定相关性（否则 PCA 收益有限）。

## 核心公式

**第一步：标准化**

```
x̃_ij = (x_ij - μ_j) / σ_j
```

**第二步：计算协方差矩阵**

```
Σ = (1/(n-1)) X̃^T X̃
```

**第三步：特征值分解**

```
Σ v_k = λ_k v_k,   λ_1 ≥ λ_2 ≥ ... ≥ λ_p ≥ 0
```

特征向量 v_k 即第 k 主成分的**载荷向量**（loading）。

**第四步：选取主成分数量**

```
累计方差贡献率 = sum_{k=1}^{r} λ_k / sum_{k=1}^{p} λ_k ≥ 85%
```

**第五步：投影（降维）**

```
Z = X̃ V_r,   V_r = [v_1, v_2, ..., v_r]  （n × r 得分矩阵）
```

**综合评价得分（以方差贡献率为权重）**

```
Score_i = sum_{k=1}^{r} (λ_k / sum λ_j) * Z_{ik}
```

## 结果解读

- **载荷矩阵**：原始变量对主成分的贡献系数，绝对值大的变量对该主成分影响大。
- **碎石图（Scree Plot）**：绘制特征值 vs 主成分序号，拐点处选取 r。
- **双标图（Biplot）**：同时展示样本得分和变量载荷，直观看相似性和变量贡献。

## 论文表达模板

```
本文对 p 个指标进行 PCA，数据经 Z-score 标准化后，
计算协方差矩阵的特征值和特征向量。
前 r 个主成分的累计方差贡献率为 [值]%（≥ 85%）。
第一主成分主要反映[指标组描述]（载荷绝对值 > 0.4），
第二主成分主要反映[指标组描述]。
以各主成分方差贡献率为权重，计算综合得分，
排名前三的对象为[名称]（结果需经数据核验后引用）。
```

## 常见错误

- 未标准化直接做 PCA，方差大的指标主导主成分。
- 强行选取 2 个主成分却只解释 50% 方差，信息损失过大。
- 把主成分得分当作评价"绝对分数"，忽略负载荷的业务含义。
- 样本间协相关性低时 PCA 效果差，未检查 KMO 检验。

## 检查清单

- [ ] 数据是否标准化（均值 0，方差 1）。
- [ ] 累计方差贡献率是否达到 85% 以上（或说明选取依据）。
- [ ] 主成分载荷是否有业务解释（避免黑盒化）。
- [ ] 碎石图拐点是否与选取的 r 一致。
- [ ] 综合得分权重来源是否说明（方差贡献率 vs 主观设定）。
- [ ] 结论是否注明"综合得分依赖样本分布，新数据需重新拟合"。
