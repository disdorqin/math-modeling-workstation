# 整数规划

## 适用场景

决策变量必须为整数或 0-1 的组合优化问题：选址、排班、任务分配、背包问题、路径规划、项目选择。

## 不适用场景

- 变量本质连续，取整只是近似（用线性规划）。
- 变量规模极大（NP-hard，需启发式或近似算法）。

## 与线性规划的关系

整数规划 = 线性规划 + 整数约束。可行域从凸多面体缩小到离散格点，求解难度从多项式变为 NP-hard（一般情形）。

## 标准形式

```
min  c^T x
s.t. A x ≤ b
     x ≥ 0
     x_i ∈ ℤ  （部分或全部变量为整数）
```

**0-1 整数规划**（选/不选决策）：`x_i ∈ {0, 1}`

**混合整数规划（MIP）**：部分变量连续，部分为整数。

## 核心求解思路：分支定界法

```
1. 松弛整数约束，求解 LP 松弛得上界（最小化时）
2. 若松弛解满足整数条件 → 当前最优解
3. 若不满足 → 选一个非整数变量 x_j = v，
   分支为 x_j ≤ floor(v) 和 x_j ≥ ceil(v)
4. 剪枝：子问题界 ≥ 当前最优则剪掉
5. 重复直到所有分支被探索或剪枝
```

Python 使用 `scipy.optimize.milp`（SciPy ≥ 1.7）或 PuLP。

## 常见建模技巧

| 逻辑约束 | 建模方式 |
|---|---|
| 选 A 则必选 B | x_A ≤ x_B |
| 最多选 k 个 | sum x_i ≤ k |
| 互斥（A、B 至多选一） | x_A + x_B ≤ 1 |
| 启动固定成本 | y_j ∈ {0,1}，产量 ≤ M * y_j |

## 论文表达模板

```
本文建立 0-1 整数规划模型（或混合整数规划），
决策变量 x_i ∈ {0, 1} 表示是否选择方案 i。
目标函数为最大化[收益/最小化成本]，
约束包括[容量约束/预算约束/逻辑约束]。
采用分支定界法（经由 HiGHS/SciPy milp）求解，
最优目标值为 [值]，选择方案为 [列表]（需用户确认数据准确性后引用）。
```

## 常见错误

- 用 LP 近似 IP，四舍五入取整后约束可能被违反。
- 忽略大 M 法中 M 选取不当（过小导致约束失效，过大导致数值问题）。
- 问题规模过大时不做可行性预分析，求解超时。
- 只报告最优值，不说明选择方案的业务含义。

## 检查清单

- [ ] 是否明确哪些变量需要整数约束（全整数/0-1/混合）。
- [ ] 求解状态是否成功，若超时是否有近似可行解。
- [ ] 最优解是否满足整数约束（无小数残留）。
- [ ] 逻辑约束（互斥、依赖）是否正确编码。
- [ ] 结论是否注明"组合优化问题可能有多个等价最优解"。
