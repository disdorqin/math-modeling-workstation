# 非线性优化

## 适用场景

目标函数或约束含非线性关系的优化：利润最大化（含规模效应）、工程参数拟合、物理约束下的设计优化、多阶段资源配置。

## 不适用场景

- 目标函数和约束均为线性（用线性规划，更高效）。
- 函数不可计算梯度且黑盒评估代价极高（考虑遗传算法、粒子群等元启发式）。
- 缺少合理初始值时，局部最优陷阱风险高。

## 一般形式

```
min  f(x)
s.t. g_i(x) ≤ 0,   i = 1, ..., m   （不等式约束）
     h_j(x) = 0,   j = 1, ..., p   （等式约束）
     lb ≤ x ≤ ub                    （边界约束）
```

## KKT 最优性条件

可微问题的一阶必要条件：

```
∇f(x*) + sum_i λ_i ∇g_i(x*) + sum_j μ_j ∇h_j(x*) = 0
λ_i ≥ 0,   λ_i g_i(x*) = 0   （互补松弛）
g_i(x*) ≤ 0,  h_j(x*) = 0
```

λ_i 为不等式约束的 KKT 乘子（影子价格）。

## 凸性判断

| 类型 | 条件 | 特点 |
|---|---|---|
| 凸优化 | f 凸 + g_i 凸 + h_j 仿射 | 局部最优 = 全局最优 |
| 非凸 | 否则 | 可能有多个局部最优 |

**凸性检验**：Hessian 矩阵 ∇²f 正半定。

## Python 求解（scipy.optimize.minimize）

```python
from scipy.optimize import minimize

result = minimize(
    fun=f,
    x0=x_init,           # 初始值关键！
    method='SLSQP',      # 带约束：SLSQP / trust-constr
    jac=grad_f,          # 提供梯度可加速
    bounds=bounds,
    constraints=[{'type': 'ineq', 'fun': g},
                 {'type': 'eq',  'fun': h}]
)
```

常用方法：`SLSQP`（等式 + 不等式约束）、`trust-constr`（精度高）、`Nelder-Mead`（无梯度）。

## 多起点策略（避免局部最优）

```python
from scipy.optimize import differential_evolution
result = differential_evolution(f, bounds)  # 全局启发式
```

或从多个随机初始点运行 minimize，取最优解。

## 常见错误

- 未验证凸性，单次求解就报告"全局最优"。
- 初始值设定随意，导致收敛到差的局部最优。
- 约束写错方向（≤ vs ≥）。
- 梯度数值不稳定时未检查 Jacobian 精度。

## 检查清单

- [ ] 目标函数和约束是否可计算（无奇点、除零）。
- [ ] 是否验证解满足所有约束（代入数值检查）。
- [ ] 非凸问题是否用多起点或全局算法。
- [ ] 求解状态是否成功（`result.success = True`）。
- [ ] 是否做参数敏感性分析（关键参数变化 ±10% 的影响）。
- [ ] 结论是否注明"局部最优不保证全局最优，需结合业务判断"。
