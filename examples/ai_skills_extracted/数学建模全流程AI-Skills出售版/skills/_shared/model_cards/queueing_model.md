# 排队模型（Queueing Model）

## 适用场景

到达随机、服务随机、需要分析等待时间、队长和服务利用率的场景：窗口服务、呼叫中心、物流分拣、医院挂号、网络请求处理。

## 不适用场景

- 到达率或服务率不满足泊松/指数分布假设，且无实际数据拟合。
- 队列有优先级、批量到达或多阶段串联时，需更复杂模型（网络排队）。
- 系统是确定性的（到达和服务时间固定），用确定性调度模型。

## Kendall 记号：A/B/c/K/m/Z

常用简写：**M/M/1**（泊松到达 / 指数服务 / 单服务台）

| 符号 | 含义 |
|---|---|
| M | 泊松到达或指数服务（无记忆性） |
| D | 确定性 |
| c | 服务台数量 |
| K | 系统容量上限（默认∞） |

## M/M/1 解析公式

前提：到达率 λ，服务率 μ，**利用率 ρ = λ/μ < 1**（稳定性条件）。

```
服务台利用率：   ρ = λ / μ
平均队长（系统）：L = ρ / (1 - ρ)
平均队长（排队）：Lq = ρ² / (1 - ρ)
平均逗留时间：   W = 1 / (μ - λ)         = L / λ  （Little 定律）
平均等待时间：   Wq = ρ / (μ - λ)         = Lq / λ
```

**Little 定律（适用任意排队系统）**：

```
L = λ * W          （系统平均队长 = 到达率 × 平均逗留时间）
Lq = λ * Wq        （平均排队长 = 到达率 × 平均等待时间）
```

## M/M/c 多服务台

利用率：`ρ = λ / (c * μ)`，稳定性要求 ρ < 1

Erlang C 公式（c 台等待概率）较复杂，通常通过仿真或专业工具计算。

## 仿真方法（离散事件仿真）

当解析公式不适用时，用离散事件仿真：

```
生成到达时间序列（指数分布：T_arr ~ Exp(1/λ)）
生成服务时间序列（指数分布：T_svc ~ Exp(1/μ)）
模拟顾客进入、等待、服务、离开的事件链
统计等待时间、队长分布和利用率
```

## 论文表达模板

```
本文对[系统名称]建立 M/M/1 排队模型（或 M/M/c，c = [值]）。
根据[数据来源]估计：到达率 λ = [值]/小时，服务率 μ = [值]/小时，
系统利用率 ρ = λ/μ = [值]（< 1，满足稳定性条件）。
理论分析得：平均等待时间 Wq = [值] 分钟，
平均系统队长 L = [值] 人。
[若仿真：Monte Carlo 仿真（N = [值] 顾客）验证上述结论，
仿真平均等待时间为 [值] 分钟，与理论值偏差 [值]%。]
（参数估计误差和分布假设偏差会影响结果，需结合实测数据核验。）
```

## 常见错误

- ρ ≥ 1 仍套用 M/M/1 公式（不稳定系统，队列无限增长）。
- 把实际到达间隔和服务时间直接当指数分布，未做拟合检验。
- 用平均等待时间代替分位数（P95 等待时间才反映峰值体验）。
- 多服务台问题用 M/M/1 公式（低估系统能力）。

## 检查清单

- [ ] 稳定性条件 ρ < 1 是否满足。
- [ ] 到达间隔和服务时间是否检验指数分布假设（如 KS 检验）。
- [ ] 解析公式适用条件（M/M/1 等）是否与实际系统匹配。
- [ ] 是否报告 P95 等待时间而非仅均值。
- [ ] 仿真迭代次数是否足够（建议 ≥ 1000 顾客）。
- [ ] 结论是否注明"模型假设简化了实际系统，结果供参考"。
