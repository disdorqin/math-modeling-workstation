# 模型比较、诊断与论文就绪规范

## 模型方案

模型方案通过 Pydantic 严格 Schema：禁止未知字段、未知模型、目标泄漏、重复特征、非法 CV 折数、非法测试比例和无效主指标。验证后的方案注册为 `model_plan_validated` Artifact，正式实验只接受该 Artifact。

## 交叉验证

回归使用带固定随机种子的 KFold，分类使用 StratifiedKFold。输出每折指标、均值、标准差、相对波动、稳定性、模型排名和全量拟合诊断。单次 train/test 指标不能替代正式模型比较。

回归诊断包含 MAE、RMSE、R²、残差均值、残差标准差和 Shapiro-Wilk；分类诊断包含全量拟合 Accuracy 和 Macro-F1。全量拟合诊断只用于检查，不作为泛化性能证据。

## 敏感性分析

使用不同数据比例和随机种子重复训练最优模型。记录主指标均值、标准差、相对波动和相对性能损失。超过阈值时输出 `REVIEW`，禁止直接宣称稳健。

## PAPER_READY

机器 `assess` 必须同时确认：比较实验成功、模型选择 Artifact 合法、敏感性结果为 PASS、Artifact 哈希完整、比较与诊断产物存在。随后必须由人工 `approve` 签字，才会将指定核心 Artifact 和实验升级为 `PAPER_READY`。

审批不会自动推进论文提纲，也不会把整个实验目录全部标记为可写论文。

工程回归可使用固定种子生成的 `SYNTHETIC` Fixture 验证正向门控，但必须保留数据类型；该验收不能替代真实赛题数据的论文审批。
