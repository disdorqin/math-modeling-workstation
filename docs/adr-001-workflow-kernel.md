# ADR-001：保留自研内核，LangGraph 作为可选适配器

## 状态

Accepted，2026-07-21。

## 决策

案例、产物、数据集、DAG 状态、Checkpoint、异常和审批继续由本项目内核管理。LangGraph 不进入这些对象的持久化格式，而通过后续 Adapter 调用 `WorkflowService`。

## 原因

- 案例目录和证据链需要长期稳定，不能随第三方框架升级迁移；
- 数学建模中的关键失败不能由 Agent 自由跳过；
- 论文数字必须来自本地执行产物，而不是框架消息状态；
- 当前内核已完成中断恢复、阻塞、降级、STALE 和人工审批测试；
- LangGraph 仍适合承担未来 LLM 节点图、暂停点和工具调用编排。

## 后果

- 第三方框架可以更换；
- 需要维护一个薄 Adapter；
- 所有第三方节点必须提交结构化结果，再由内核注册产物和推进状态；
- 禁止第三方节点直接修改 `status.json` 或 Checkpoint。
